# AI SUMMER SCHOOL 2026 出席カレンダー

Google スプレッドシートと Google Apps Script で動く、サマースクール向けの出欠管理 Web アプリです。

## 入っている機能

- 月間カレンダー表示
- 講座詳細表示
- 名前選択 + 出席 / 欠席 / 未定 の登録
- 既存回答の上書き更新
- 出席予定者と未回答者の表示
- 自分の回答一覧
- 本日の講座 / 次回講座の管理画面
- 参加予定者一覧のコピー
- 初期シート作成
- サンプルデータ投入

## ファイル構成

- `Code.gs`: GAS バックエンドとスプレッドシート処理
- `Index.html`: Web アプリ UI
- `appsscript.json`: GAS マニフェスト

## セットアップ

1. Google スプレッドシートを 1 つ新規作成
2. そのスプレッドシートで Apps Script を開く
3. このフォルダ内の `Code.gs` `Index.html` `appsscript.json` を貼り付け
4. 別スプレッドシートを使いたい場合は `Code.gs` の `CONFIG.SPREADSHEET_ID` に ID を設定
5. ウェブアプリとしてデプロイ

`CONFIG.SPREADSHEET_ID` を空文字のままにすると、スクリプトが紐づくスプレッドシートをそのまま使います。

## 自動作成されるシート

### `講座一覧`

| 講座ID | 開催日 | 開始時刻 | 終了時刻 | 講座名 | 講師名 | 開催方法 | 詳細URL | 受付状況 | 公開状態 | 備考 |
|---|---|---|---|---|---|---|---|---|---|---|

### `参加者`

| 参加者ID | 名前 | メール | Discord名 | 利用状態 | 確認番号 |
|---|---|---|---|---|---|

### `出欠回答`

| 講座ID | 参加者ID | 名前 | 回答 | 回答日時 | 更新日時 |
|---|---|---|---|---|---|

## 運用メモ

- `利用状態` が `無効` の参加者は一覧に出ません
- `公開状態` が `非公開` の講座は表示されません
- 参加者名を一般画面に出したくない場合は `CONFIG.SHOW_PARTICIPANT_NAMES` を `false` に変更してください

## 最初の確認方法

1. Web アプリを開く
2. `本日の講座` タブへ移動
3. `サンプル投入` を押す
4. カレンダーと出欠登録の動きを確認
