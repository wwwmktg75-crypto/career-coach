# 01_生成AI仕事術 前半スライド

静的な `HTML / CSS / JavaScript` で作ったスライドです。  
`index.html` を開くだけで閲覧できます。

## ファイル構成

- `index.html`
- `styles.css`
- `app.js`

## 開き方

1. `index.html` をブラウザで開く
2. 左の目次から任意のスライドへ移動する
3. `← / →` または `PageUp / PageDown` でも移動できる

## PDFにする

1. 画面右上の `印刷 / PDF` を押す
2. ブラウザの印刷画面で `PDFとして保存` を選ぶ
3. 印刷は `横向き` を推奨
