# AIの歩き方 2026年8月最新版

## 90分アウトライン

- 最終更新: 2026-08-09
- 対象: 非エンジニア中心の初中級者
- 形式: 講義 + 実務イメージ + 質疑
- 基本方針: `小さく試し、確認し、仕組みにする`
- 現在のスライド基準: `slides/index.html` / 全32枚

## 全体構成

### 0. オープニング `5分`

- タイトル確認
- 今日のゴール共有
- この講座で目指すこと
  - AIの正体を知る
  - 使いどころを見つける
  - 小さく試して続ける

### 1. 序章 `10分`

- AI初心者3つの心構え
  - 焦らない
  - 課題から考える
  - 惑わされない
- 初めに
  - 自分に必要なこと・やりたいことに落とし込む
  - 経験値を積み上げる
- 全体マップ

### 2. 第1章 生成AIの正体と2026年の新常識 `30分`

- LLMとは何か
  - `aboutllm.png` で基本イメージをつかむ
- 生成AI開発は国家間の競争に入っている
  - `slide-7-ai-dev.png` で全体構図を視覚的に理解する
- AIはどう文章を作るのか
  - `AI-word.png` で仕組みを視覚的に理解する
- 得意なこと / 任せきってはいけないこと
  - 壁打ち相手として優秀で、何度でも気兼ねなく聞ける点も押さえる
- マルチモーダルの基本
- モデルの選び方
  - どのモデルでもある程度の実務はこなせる
  - 速さなら ChatGPT、深さなら Claude、Google環境なら Gemini
- 無料版と有料版の考え方
  - `slide-12-kakin.png` で、無料版の限界と課金が必要になる場面を視覚的に理解する
- チャット型AIとPC操作・実行型AIの違い
  - `slide-13-desktop.png` で違いを視覚的に理解する
- LLM提供サービスと上物サービスの違い
  - `uwamono.png` で役割の層の違いを視覚的に理解する
- 2026年の新常識

### 3. 第2章 最重要トレンド `15分`

- チャットからAIエージェントへ
  - `agent.png` で1問1答から自律実行への変化を視覚化する
- AIとの関わり方の進化
  - `プロンプト → コンテキスト → ハーネス → ループ`
- `Human in the loop` から `Human on the loop` へ
- 個別スキルよりメタスキル
- 人は方向づけと最終判断を担う

### 4. 第3章 失敗しないためのルール `15分`

- 5大リスクで整理する
  - 情報漏えい
  - 誤情報・ハルシネーション
  - 著作権・権利侵害
  - セキュリティリスク
  - AIの勝手な実行・誤操作
- 基本ルール
  - AIに秘密を入れない
  - AIを100%信じない
  - AI生成物をそのまま公開しない
  - AIも騙される前提で権限を絞る
  - 重要操作は人間承認を入れる

### 5. 第4章 学びをつなげて、仕事で「できる」に変える `15分`

- 複数講座を組み合わせると、何が作れるかを見る
- 調査・資料作成・発信・自動化・AI委任をつなげる
- 「やりたいこと別」におすすめの組み合わせを理解する
- 自分に必要なAIスキルだけを選んで組み合わせる

### 6. まとめ・質疑 `10分`

- 最後のメッセージ
- メッセージビジュアル
- 受講者の業務への置き換え
- 質疑応答
